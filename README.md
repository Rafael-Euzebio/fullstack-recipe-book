# Instructions

## Disclaimer
**This project's Frontend was rewritten in Vite due to performance issues faced with Next during development**

### Frontend
```
cd frontend
npm install
npm run dev
```

### Backend
The backend runs on port 8080. Make sure no other script is running on it. If it's not possibble to run on port 8080, modify: 
- `VITE_BACKEND_URL` under `./frontend/.env` 
- `PORT` under `./backend/.env` 

```
cd backend
npm install
npm run start:dev
```
